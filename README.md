# Car Sales App

WPF aplikace v C# pro načtení XML souboru s prodanými vozy.

## Funkce

* načtení XML souboru
* filtrování víkendových prodejů
* výpočet ceny s DPH
* seskupení podle modelu vozu
* zobrazení dat v GUI

## Technologie

* C#
* WPF

## Struktura XML

```xml
<Cars>
  <Car>
    <Model>Škoda Fabia</Model>
    <SaleDate>2010-12-05</SaleDate>
    <Price>350000</Price>
    <VAT>20</VAT>
  </Car>
</Cars>
```
